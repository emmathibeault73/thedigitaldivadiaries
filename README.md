# The Digital Diva Diaries

Website for The Digital Diva Diaries, a social media management business run by Emma.

## What's here

- `index.html` is the whole homepage: services, specialties, packages, a sample week of posts, the About section and the contact form.
- `emma.jpg` is the photo used in the About section.

## Contact form

The form saves inquiries to the `leads` table in the **digital-diva-diaries** Supabase project. Visitors can only add a lead; they can't read anyone else's. Check new inquiries in Supabase under Table Editor → `leads`.

The key in `index.html` is Supabase's publishable key, which is meant to be public.

## Putting it online

Turn on GitHub Pages (Settings → Pages → Deploy from branch → `main`, folder `/ (root)`), and the site goes live at `https://emmathibeault73.github.io/thedigitaldivadiaries/`.
